# 📄 NoPaper

A modern Android application designed to reduce paperwork by digitizing document storage, management, and sharing. NoPaper provides a clean and efficient experience for capturing, uploading, and organizing documents digitally.

---

# 🚀 Features

* 📷 Capture documents using camera
* 🖼️ Upload files from gallery
* 📂 Smart digital document management
* ⚡ Fast and lightweight performance
* 🎨 Modern UI/UX design
* 🔐 Organized and secure workflow
* 📱 Smooth Android native experience

---

# 🛠️ Tech Stack

* Android Studio
* Java / Kotlin
* XML
* Firebase
* Android SDK
* Material Design
